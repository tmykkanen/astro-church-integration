# 03: Theme styles and a client script reach the built Site

**Spec:** `.scratch/package-skeleton/spec.md` · **PRD:** FR-6, NFR-3 · **ADRs:** 0005
**Blocked by:** 02
**Status:** ready-for-human

## Behaviour
The Theme's stylesheet declares `@source` for its own files, so Tailwind generates classes used only inside the Theme, even when the Theme sits in `node_modules`. Tailwind classes in the Site's content are picked up by Tailwind's automatic detection, with no Theme configuration. A client `<script>` on the route ships too.

## Acceptance criteria
- [ ] The skeleton route uses a Tailwind class that appears only in Theme files, and the Theme stylesheet declares `@source` for them.
- [ ] The Starter Site has one content file using a Tailwind class that appears nowhere else.
- [ ] Both classes are in the packed install's built CSS.
- [ ] The route's client `<script>` is in the packed install's build output.
- [ ] If automatic detection misses Site content, the fallback (an absolute `@source` generated by the integration) is recorded in Comments and the spec.
