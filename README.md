# Astro Church

A church-website Theme for [Astro](https://astro.build), shipped as the npm integration `astro-church`.

This repo is a work in progress: the Theme is being converted from code copied into each Site into an integration. The package README ([`packages/astro-church/README.md`](./packages/astro-church/README.md)) is the place to start.

## Repository layout

- `packages/astro-church/`: the Theme
- `playground/`: the Starter Site, used to develop and test the Theme
- `docs/`: the PRD, ADRs, research and workflow
